Career Track Analysis with SQL and Tableau

📌 Project Overview

This project analyzes career track enrollments and achievements of 365’s students. The goal is to extract key insights using SQL and visualize the findings in Tableau for better interpretation and decision-making.

🛠️ Technologies Used

SQL - To retrieve and manipulate enrollment and achievement data.

Tableau - To visualize trends and patterns in career track progress.

🔹 Project Workflow

Data Extraction: Retrieve necessary data from the SQL database.

Data Processing: Clean and transform the data for visualization.

Visualization: Develop dashboards in Tableau to display insights.

Interpretation: Analyze trends in student enrollments and achievements.

This project helps in understanding how students progress through different career tracks, aiding in decision-making for curriculum improvements and better student engagement strategies.
